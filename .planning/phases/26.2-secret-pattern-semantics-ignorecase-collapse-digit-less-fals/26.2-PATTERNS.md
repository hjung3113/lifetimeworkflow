```json
{
  "version": "v1",
  "gates": { "...": "unchanged — 5 gate entries, do not touch" },
  "secret_patterns": [
    "AKIA[0-9A-Z]{16}",
    "(?:api[_-]?key|secret|password|token)\\s*[:=]\\s*(?=[^\\s]{20,})(?=[^\\s]*[A-Z])(?=[^\\s]*[a-z])(?=[^\\s]*[0-9])[^\\s]{20,}",

    "eyJ[A-Za-z0-9_-]{10,}\\.[A-Za-z0-9_-]+\\.[A-Za-z0-9_-]+",
    "Authorization:\\s*Bearer\\s+[^\\s]+"
  ]
}
```
Indices 0 and 2–7 must stay byte-identical (same constraint 26.1 applied). Index 1's replacement
must:
1. Scope the `[A-Z]`/`[a-z]` lookaheads with `(?-i:...)` so they survive the outer `re.IGNORECASE`
   both consumers apply (closes CR-01) — verified functional in RESEARCH.md's "CR-01 candidate
   fix" code example.
2. Reach an explicit disposition on the digit requirement (WR-01) — RESEARCH.md's recommended
   option is length-floor + 2-of-{`(?-i:[A-Z])`, `(?-i:[a-z])`, `[0-9]`} rather than an
   unconditional AND on all three; see RESEARCH.md "WR-01 candidate fix shape" for the pure-regex
   disjunction form. Whichever disposition is chosen, it must be recorded (SC-2/SC-4), and the
   SC-1 `ci.yml` red-green proof must be re-run against it (guard against reopening 26.1's original
   false positive).

**Write-path gate:** identical `contracts/**` CODEOWNERS + `contract_guard` PreToolUse gate as

```python
def test_sensitive_output_is_refused_without_plaintext_artifact(
    tmp_path: Path, monkeypatch: pytest.MonkeyPatch
) -> None:
    # Fixture value is 20+ chars with upper/lower/digit charset diversity -- must satisfy the
    # tightened generic secret_patterns[1] gate (26.1: min-20 + 3-way charset diversity), not
    # just be a plausible-looking password string.
    root = packet(tmp_path)
    registry = tmp_path / "registry.json"
    command = ["uv", "run", "pytest", "-c", "password=Sup3rSecretValue1234567890"]
    registry.write_text(
        json.dumps(
            {
                "version": "v1",
                "gates": {"fixture": {"argv": command, "criterion_pattern": "^AC-[0-9]{2,}$"}},
                "secret_patterns": json.loads(capture_module.GATE_REGISTRY.read_text())[
                    "secret_patterns"
                ],
            }
        ),
        encoding="utf-8",
    )
    monkeypatch.setattr(capture_module, "GATE_REGISTRY", registry)
    with pytest.raises(EvidenceRefusal):
        capture(root, "fixture", command)
```
Note this idiom already reads `secret_patterns` from the LIVE `capture_module.GATE_REGISTRY`
(`json.loads(...)["secret_patterns"]`), so it automatically picks up this phase's contract edit —
its own docstring comment (lines 152-154) even calls out the 26.1 constraint explicitly and will
need a comment update referencing 26.2's CR-01/WR-01 fix, per the file's own convention of dating
gate-shape assumptions in the test comment.
