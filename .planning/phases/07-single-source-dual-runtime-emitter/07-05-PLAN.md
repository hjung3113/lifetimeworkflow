## Phase Goal

**As a** harness maintainer, **I want to** compile the single runtime-neutral `harness/` source into both runtime artifact trees, merging (not overwriting) the live `.claude/settings.json` GSD hook wiring, **so that** the runtimes stay byte-faithful to one source without breaking the GSD SessionStart wiring the repo depends on. This plan delivers the second and riskiest merge surface: the settings.json signature merge and the Pitfall-4 double-wiring hazard.

<objective>
Deliver `merge.py`'s JSON regime (Regime B-json): a signature-matched hook-group merge into the LIVE `.claude/settings.json`, resolving the Pitfall-4 double-wiring hazard explicitly. The Phase 2/4 harness hooks + `memory-inject.sh` are ALREADY hand-wired and guarded by `tools/memory_regen/tests/test_hook_wiring.py` (exactly 4 SessionStart groups). The MVP path is idempotent coexistence: the merge must reproduce the existing file byte-for-byte and MUST keep the group count at 4.

Purpose: This is the single highest-risk surface in the phase. A naive re-wire produces a 5th SessionStart group and breaks the GSD session bootstrap. Getting the signature match + deterministic reinsert right is what lets the emit-drift gate diff `.claude/settings.json` cleanly.

Output: `merge.py` signature merge, `test_settings_merge.py`, an extended `test_coexist.py`, and the reproduced-byte-identical `.claude/settings.json` committed.
</objective>
