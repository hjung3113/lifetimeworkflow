## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `--out` directory ↔ `--target` directory | Must never overlap; a scan must never be able to read its own prior output as if it were part of the target (self-pollution). |

| `destinations.py`'s disposition chain ↔ the CODEOWNERS-gated constitution plane | The chain must never assign anything OTHER than `human-ratification-required` to a constitution-plane path, regardless of existing-file state. |
