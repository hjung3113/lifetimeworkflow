<objective>
Repair OBS-D-03 in both halves: give `conventions_for()` a permanent `lint` key (D-11), and make an
adopted target's JavaScript lint/test commands come from that target's own `package.json` scripts
(D-12) rather than from a harness-side default that assumes the target's toolchain.

Purpose: RTA-04/SC-4 requires each adopted package to resolve a nearest-wins convention profile
containing its lint and test commands. Phase 51 found the JavaScript profile had `test`, `format`
and `bash_scope` all `null` and **no `lint` key at all**.

Output: the widened profile shape, a pure target-scripts→`[[languages]]` derivation wired into
draft and apply, and a repo-local end-to-end test that resolves a real profile out of a synthetic
adopted target.
</objective>
