`_apply_marker_merge(destination, target_path, block_body="")` (`apply.py:292`) computes its lock
path as `target_path.with_name(f".{target_path.name}.lock")` and holds it with
`fcntl.flock(lock.fileno(), fcntl.LOCK_EX)` across the whole read-merge-write. For the three
`MARKER_CAPABLE` destinations (`AGENTS.md`, `CLAUDE.md`, `.claude/settings.json`) that yields
exactly the three sidecars Phase 51 observed: `.AGENTS.md.lock`, `.CLAUDE.md.lock`,
`.claude/.settings.json.lock`.

Do NOT modify, reorder, or wrap: `_read_target_no_symlink` (`apply.py:270-289`, the symlink
read-through mitigation), `_atomic_replace`, `atomic_create`, `refuse_unsafe_destination`. The only
change inside `_apply_marker_merge` is the prior-run probe and its stderr report; the lock itself
is never released early and never unlinked.

**The D-15 / D-16 tension, resolved by honest wording — read this before writing the message.**
D-15 forbids unlinking the sidecar. Therefore `lock_path.exists()` is True on EVERY run after the
first — a normal second run and a crash-interrupted run are INDISTINGUISHABLE by that predicate
alone. A message calling this condition "stale" would be false on ~100% of Phase-53 re-runs, and the
fresh-target negative control (which only covers never-run-before) cannot catch that degeneracy.
This plan therefore reports what it can actually prove: **a lock sidecar from a prior run was
present and has been acquired**. It is a provenance note, not an alarm. Narrowing it into a real
staleness signal (owner pid recorded in the sidecar and probed for liveness, or an mtime compared
against run start) is deliberately NOT built here — it is new machinery with no observation behind
it, and NG-01 forbids speculative surface. Record the limitation explicitly in the SUMMARY so
Phase 53's re-run semantics inherit a known gap rather than a false signal.

`tools/adoption_apply/tests/test_atomic_apply.py:265-270` carries a standing instruction: NEVER
assert the mere existence of the `.lock` sidecar — that assertion held even with the `fcntl.flock`

pattern for proving mutual exclusion.
