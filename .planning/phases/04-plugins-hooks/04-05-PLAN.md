## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| staged tree -> commit (VCS) | The last chance to block an unratified contract/golden change or a §4.3-4.6 violation from entering history. |
| Bash tool_input.command -> git subcommand classifier | Untrusted command string; must be classified by token-walk, never shell-interpolated. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-13 | Tampering | a real gate silently disabled when .NET absent | mitigate | Only golden-parity is SKIPped (logged) when dotnet absent; contract-drift + polyglot ALWAYS run; unit test asserts the SKIP does not suppress a drift/polyglot block (D-06). |
| T-04-14 | Elevation of Privilege | command injection via tool_input.command | mitigate | Classify git subcommand via token-walk (gsd-validate-commit.sh precedent); `subprocess.run([list], shell=False)` for `git diff --cached` and all children. |
| T-04-15 | Repudiation | matrix trailing catch-all allow shadows a deny (P3) | mitigate | test_order_resolution proves the last matching rule for an unknown command is `ask`, not `allow`, and constitution edits resolve to deny. |
| T-04-16 | Denial of Service | Stop-hook commit gate loops / fires at wrong time | mitigate | Primary surfaces are the git pre-commit shim + a `--from-hook` Bash(`git commit`) matcher; Stop is not used as the blocking surface (Pitfall 6). |
| T-04-SC | Tampering | dependency supply chain | accept | Zero new packages — composes in-repo drift/golden/polyglot + stdlib; `uv.lock` unchanged. |
