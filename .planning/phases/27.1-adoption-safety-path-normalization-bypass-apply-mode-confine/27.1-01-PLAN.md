<objective>
Close CR-01 and CR-02 from `27-REVIEW.md`: `apply.py`'s constitution-plane refusal and root
confinement are each correct sibling functions that are not wired into every write path a hostile
or malformed `manifest.json` can reach. Introduce one new choke-point function,
`refuse_unsafe_destination`, that `apply_disposition` funnels every destination through — per D-01,
`refuse_if_constitution` stays an unchanged thin wrapper so Phase 27's own two direct-call tests
keep passing unmodified. Also close WR-01 (unlocked marker-merge read-modify-write) and a
research-found symlink read-side information-leak in the same file, since both are in-scope edits
to the same module and test files.

Purpose: `apply.py`'s own docstring claims its constitution refusal is "structural… independent of
any Claude hook" — CR-01/CR-02 prove that claim false under an adversarial `destination` spelling.
This plan makes the code match the claim.
Output: `refuse_unsafe_destination` wired into `apply_disposition`; a locked, symlink-safe
`_apply_marker_merge`; a widened adversarial-input regression suite that fails against the
currently-shipped code before the fix lands (standing rule).
</objective>

`def refuse_if_outside_root(path, root) -> None:` resolves both `path` and `root` via
`Path(...).resolve()` and raises `PathEscapeError` if the resolved path is not the resolved root or
a descendant (`resolved_root not in resolved_path.parents`).

`tools/adoption_apply/apply.py:188-206` (`apply_disposition`, current call site to change):
line 204-206 currently reads `destination = record["destination"]`;
`disposition_value = record["disposition"]`; `refuse_if_constitution(destination)`; line 213 then
independently recomputes `target_path = Path(target_root) / destination`. This plan replaces the
`refuse_if_constitution(destination)` line with a single call to the new
`refuse_unsafe_destination(destination, target_root)`, which returns the already-resolved
`target_path` — the subsequent `create`/`marker-merge` branches use that returned value instead of
recomputing `Path(target_root) / destination`.

`tools/adoption_apply/batch.py:165-192` (`update_status`) — the `fcntl.flock` sidecar-lock idiom to
copy verbatim into `_apply_marker_merge`: `lock_path = path.with_name(f".{path.name}.lock")`;
`lock_path.parent.mkdir(parents=True, exist_ok=True)`; `with lock_path.open("a+b") as lock:
fcntl.flock(lock.fileno(), fcntl.LOCK_EX)` — hold the lock across the ENTIRE read + merge + write
sequence, not just the write.

`tools/adoption_apply/apply.py:166-185` (`_apply_marker_merge`, current unlocked body to wrap) —
reads `target_path.read_text(encoding="utf-8")` (text case) or
`json.loads(target_path.read_text(encoding="utf-8"))` (json case) guarded only by

links"` on this platform when the final path component is a symlink).

`tools/adoption_apply/apply.py:39-51` (module imports) — `os`, `Path`, `json`, `tempfile` already
