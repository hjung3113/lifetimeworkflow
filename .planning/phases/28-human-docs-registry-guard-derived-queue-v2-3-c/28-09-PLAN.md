<objective>
Close the write side of the docs-plane self-green hole: make it structurally impossible for an agent
to author a ledger disposition.

Purpose: the Phase 29 researcher found that `docs/.docs-review-ledger.toml` is unguarded on every
write surface in the repo. Combined with D-04's content-bound `reviewed-no-change`, an agent could
land a brand-new binding plus a matching ledger row and self-bless it green — precisely what this
phase exists to prevent. Plan 28-04 closes the greenness side (`first_seen-unratified`); this plan
closes the write side. Both are needed: one stops the write, the other means a write that slips
through still cannot produce green.

Output: `REVIEW_LEDGER_GLOBS` + `ReviewLedgerRefusal` at the existing 27.1 choke point, and a
`path_deny_globs` entry covering the ordinary agent Write/Edit path, round-tripped through the
emitter.
</objective>
