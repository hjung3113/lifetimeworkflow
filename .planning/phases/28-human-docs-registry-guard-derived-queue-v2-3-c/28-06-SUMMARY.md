## Design notes

- **Row count, not file emptiness.** The generator always renders a stable non-empty file (header +
  `EMPTY_MARKER` when nothing qualifies) so `main()` is idempotent, while the injector counts the
  table's data rows — `lines starting with "| "` minus the header and separator — so an empty queue
  and an absent queue are indistinguishable in the payload.
- **`SUPERSEDING_ADR_REQUIRED`** qualifies on the reviewed DISPOSITION as well as on state. It can
  never make a binding green (`guard.py` step 3), so it is always already in `QUEUE_STATES`; the
  explicit disjunction keeps that coupling from being an accident rather than a rule.
- **`_read_head` deliberately unused** — it returns `_HEAD_LINES = 20` lines and would make the
  section grow with the queue, breaking the budget invariant.
