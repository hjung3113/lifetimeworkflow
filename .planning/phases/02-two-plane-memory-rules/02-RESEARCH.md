## Summary

Phase 2 is an all-Python tooling phase (the `.NET` egress block is irrelevant here). Every dependency is on PyPI and was **functionally installed and imported in-session** — the tree-sitter symbol-extraction recipe and networkx PageRank determinism are verified, not assumed. The work splits into four buildable pieces plus two layout/rules pieces:

1. **repo-map generator** — tree-sitter (self-contained grammar wheels for Python + C# + Bash) parses the monorepo into def/ref symbols; a networkx directed graph is ranked by PageRank; the top-N files with elided signatures render into `.memory/derived/repo-map.md`. Determinism (delete+regen identical) is achieved by sorted iteration, no timestamps in the body, and stable `(-score, path)` tie-breaking.
2. **contracts-index generator** — scans `contracts/**/*.schema.json` + companion YAML and **reuses the existing `tools.contract_hash` + `tools.contract_drift` modules** to attach live drift-hash status per contract, emitting `.memory/derived/contracts-index.md`.
3. **Claude SessionStart injector** — a hook appended (coexisting, not overwriting) to the 4-slot `.claude/settings.json` `SessionStart` array, wrapping a pure Python *payload assembler* whose output is a ~1k-token pointer/index summary with a provisional banner and priority-truncation. The assembler is the unit-tested seam; the hook wiring is config.
4. **opencode injection contract (authored, deferred)** — a TS plugin stub that shells out to the *same* assembler, documenting the single injection contract both runtimes honor.

Plus `.memory/` two-plane layout with a refined gitignore (D-03), and root + per-package `AGENTS.md` with the P11 backstop: non-negotiable invariants live in the injector/hook and are *restated* per-package, never inherited-only.

**Primary recommendation:** Build one Python package `tools/memory_regen/` (new uv-workspace member) exposing three entrypoints — `repo_map`, `contracts_index`, `inject` (the shared assembler). Pin `tree-sitter==0.25.2`, `tree-sitter-python==0.25.0`, `tree-sitter-c-sharp==0.23.5`, `tree-sitter-bash==0.25.1`, `networkx==3.6.1`. Prove determinism with a committed syrupy snapshot test (not `git diff`, because `.memory/derived/` is gitignored). The Claude hook is a thin bash/node wrapper emitting the `{hookSpecificOutput:{additionalContext}}` envelope — identical shape to the existing `gsd-session-state.sh`.

### Pattern 1: Self-contained tree-sitter symbol extraction (tree-sitter 0.25 API)
**What:** Load a grammar from its wheel, parse a file, run a def/ref query with `QueryCursor`.
**When to use:** repo-map, per source file.
**Example (validated in-session — this exact code ran):**
```python
# Source: functionally verified 2026-07-08, tree-sitter 0.25.2
import tree_sitter as ts
import tree_sitter_python as tspy

lang = ts.Language(tspy.language())          # wrap the wheel's PyCapsule
parser = ts.Parser(lang)
tree = parser.parse(src_bytes)
query = ts.Query(lang,                        # 0.25: Query() constructor, NOT lang.query()
    "(function_definition name: (identifier) @def)\n"
    "(call function: (identifier) @ref)")
cursor = ts.QueryCursor(query)                # 0.25: captures() moved to QueryCursor
caps = cursor.captures(tree.root_node)        # -> {"def": [Node,...], "ref": [Node,...]}
# caps["def"] = ['foo','bar'] ; caps["ref"] = ['bar']
```
**API note (breaking vs training data):** in tree-sitter 0.25, `Language.query()` and `Query.captures()` are **deprecated/removed**; use `ts.Query(lang, s)` + `ts.QueryCursor(query).captures(node)`. Training-data examples using `lang.query(...).captures(...)` will fail with `AttributeError`. [VERIFIED: reproduced the failure then the fix in-session]

### Pattern 2: Deterministic PageRank ranking
**What:** Build a directed file→file graph (edge A→B when A references a symbol defined in B, weighted by count), rank with `networkx.pagerank`.
**When:** repo-map ranking step.
**Determinism rules (all required for delete+regen identical):**
- Insert nodes and edges in **sorted order** (Python dict preserves insertion order; PageRank's uniform start vector is then order-stable).
- Select top-N by `sorted(scores.items(), key=lambda kv: (-kv[1], kv[0]))` — score desc, **path asc tie-break**.
- **Do not print raw float scores** in the output body (or round to a fixed dp). Ranking order is stable; printed floats are the determinism trap.
- **No timestamp / no `generated-at`** anywhere in the file body. The "DERIVED — do not hand-edit" marker is static text.
```python
# Source: networkx 3.6.1, determinism confirmed in-session (pagerank(g)==pagerank(g))
import networkx as nx
g = nx.DiGraph()
for a, b, w in sorted(edges):          # sorted → stable
    g.add_edge(a, b, weight=w)
ranked = sorted(nx.pagerank(g, weight="weight").items(), key=lambda kv: (-kv[1], kv[0]))
```

## Common Pitfalls

### Pitfall 1: Non-determinism from floats/timestamps (breaks success criterion 2)
**What goes wrong:** repo-map or contracts-index embeds a generation timestamp or raw PageRank floats; delete+regen produces a byte-different file.
**Why:** "generated at" feels informative; float repr varies subtly.
**How to avoid:** No timestamps in the body; rank-only (don't print scores) or round to fixed dp; sorted iteration; stable `(-score, path)` tie-break. Prove with a committed syrupy snapshot.
**Warning signs:** snapshot test flaps; two consecutive runs differ.

### Pitfall 2: `git diff` used as the determinism proof on a gitignored file
**What goes wrong:** CONTEXT.md specifics line 81 says "git diff 없음", but D-03 gitignores `.memory/derived/` — a gitignored file never shows in `git diff`, so the test is a silent no-op (always "passes").
**How to avoid:** Determinism test = generate → hash → delete → regenerate → assert byte-identical (or syrupy snapshot against a committed golden fixture stored under `tools/memory_regen/tests/__snapshots__/`, NOT under `.memory/`). Flag this reconciliation to the planner.
**Warning signs:** a determinism test that touches `.memory/derived/` and asserts on `git status`/`git diff`.

### Pitfall 3: tree-sitter 0.25 API drift from training data
**What goes wrong:** `lang.query(s).captures(node)` throws `AttributeError` (`Query` has no `captures`) on 0.25.
**How to avoid:** Use `ts.Query(lang, s)` + `ts.QueryCursor(query).captures(node)` (Pattern 1). Pin tree-sitter to 0.25.2.
**Warning signs:** `DeprecationWarning: query() is deprecated`; `AttributeError: 'tree_sitter.Query' object has no attribute 'captures'`.

### Pitfall 4: Injection payload exceeds the ~1k cap under context bloat (Pitfall 2 in PITFALLS.md)
**What goes wrong:** contracts-index summary + full repo-map is dumped, blowing the budget; instructions get buried.
**How to avoid:** `assemble()` enforces a char budget (~4000 ≈ 1k tokens); priority order = [provisional banner → drift status → contracts-index summary → repo-map top-N → activeContext pointer]; **priority-truncate whole low-priority sections**, never mid-line blind-truncate (D-07). Unit-test: assert `len(payload) <= budget` and banner+drift always present even when repo-map is dropped.
**Warning signs:** payload measured in tens of KB; a narrow task's context contains full contract text.

### Pitfall 5: Non-negotiable rules dropped inside a package (P11)
**What goes wrong:** A Codex-style runtime *replaces* rather than concatenates nested `AGENTS.md`; the root's contract-first / §4-5 boundary invariants vanish exactly inside `libs/dotnet/`.
**How to avoid:** (a) Each per-package `AGENTS.md` is self-sufficient — restate (or explicitly reference) the non-negotiables. (b) The non-ignorable injector carries the invariants regardless of which `AGENTS.md` loaded. (c) True enforcement is Phase-4 hooks — prose is advisory. See what-goes-where table below.
**Warning signs:** a root invariant holds at repo root but not when working deep in a package.

### Pitfall 6: Auto-captured volatile memory laundered as fact (P13)
**What goes wrong:** `activeContext.md` holds a mid-session guess; non-ignorable injection makes every future session trust it.
**How to avoid:** Inject only a **pointer** to activeContext (not its full body), always under the provisional banner ("volatile — confirm against contracts/ADR"). Decisions belong in append-only ADR, never in `.memory/state/`. Success-criterion-4 test: banner present; a conflict test asserts ADR wins.

from pathlib import Path
from tools.contract_hash.hash import build_manifest, CONTRACTS_DIR
from tools.contract_drift.drift import run_gate

KIND = {"log-specs": "log-spec", "normalization": "normalization",

def index_rows():

### Assembler skeleton (the tested seam)
```python
# tools/memory_regen/inject.py
BANNER = ("PROVISIONAL — volatile session state below is a hint, not truth. "
          "contracts/ and docs/adr/ ALWAYS override .memory/ on conflict.")

def assemble(budget_chars: int = 4000) -> str:
    sections = [
        ("banner",   BANNER),                          # priority 0 — never dropped
        ("drift",    _drift_summary()),                # priority 1
        ("contracts",_contracts_summary()),            # priority 2
        ("repomap",  _repo_map_topN()),                # priority 3 — dropped first
        ("active",   _active_context_pointer()),       # priority 4 (pointer only)
    ]
    out, used = [], 0
    for _name, text in sections:                       # already in priority order
        if used + len(text) + 1 > budget_chars and _name not in ("banner", "drift"):
            continue                                   # priority-truncate whole section
        out.append(text); used += len(text) + 1
    return "\n".join(out)
```
