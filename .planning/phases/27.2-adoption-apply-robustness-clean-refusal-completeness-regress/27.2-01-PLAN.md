## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Manifest content (`destination` string) → `apply.py` write path | Untrusted: a manifest may be hand-edited, tampered with, or drafted against a hostile tree between draft and apply. `refuse_unsafe_destination` is the sole choke point. |
| On-disk `approval.json` → `check_valid` | Untrusted: the file may be truncated by a crash, hand-edited, or replaced. It must never be able to crash the gate. |
| `apply.py` exceptions → `cli.py` exit codes | The CLI's `except` tuple is the contract boundary between an internal fault and a documented exit code. |
| Agent session → `contracts/`, `docs/adr/`, `golden/` | Not crossed by this plan (D-08). `contract_guard` remains the enforcement layer if it ever is. |
