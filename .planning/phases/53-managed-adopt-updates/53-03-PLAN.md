<objective>
Wire the classification layer from Plan 02 into the actual apply cycle, so that re-running `/adopt`
updates what it installed, no-ops when nothing moved, and refuses to touch a file its owner edited.

Three moving parts:
1. `apply.py` — an `update` branch that durably replaces via `_atomic_replace`, and a summary that
   distinguishes `updated` / `unchanged` / `conflicts` from `applied` / `skipped` / `refused`.
2. `cli.py` — draft reads the target's record and compares against the payload apply would ACTUALLY
   write (post-splice); apply writes the record back only when it changed, and names each conflict
   on stderr with both hashes.
3. The paired positive/negative end-to-end tests 53-VALIDATION.md makes blocking.

Purpose: this is where all three MONO-12 success criteria become observable. It is also where the
phase is most exposed to its own signature defect — a suite that tests only the no-op passes even if
the `update` branch is deleted entirely.

Output: a re-runnable `/adopt apply`, with WR-07 and WR-08 closed as side effects.
</objective>
