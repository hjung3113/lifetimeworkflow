## Integration

Verified by execution, not by reading summaries:

- **The 47 → 48 → 49 chain composes for real.** `conventions_for()` imports `owning_package()`;
  `impact.report()` composes `query.py` + `compile.py` + `ownership.py` + `loader.py`. No phase

- **One traversal engine, one ownership resolver.** `owning_package()` is the only nearest-enclosing
  implementation in the tree; the no-second-engine AST gate catches while-loops,
  for/comprehension-over-adjacency and call-graph cycles, and was mutation-tested.

  convention profiles from two phases' generators; two consecutive regenerations are byte-identical, and
  `stale-derived` covers the file.
- **Surface accounting agrees everywhere.** Commands 18 → 19 (only `/impact`); skills 8 → 8. `caps.py`,
  `test_commands.py`, `test_emit_determinism.py` and `test_coexist.py` all match the live tree.
- **Emit round-trip idempotent** across every authored change (73 artifacts, clean tree twice).
- **No-growth invariant held.** `ci.yml`'s job set and `gate.needs` unchanged since `92cc635` — only the
  existing `stale-derived` step's command list grew. Zero new contracts, zero new `tools/` packages,
  nothing injected into SessionStart.
