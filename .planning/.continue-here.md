## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Happy-path-only fixtures | A guard is tested only with the input spelling it already handles. Produced CR-01/CR-02 (Phase 27) and WR-07 (Phase 27.1). Suite stays green; control is bypassable. | blocking | Adversarial-input table authored before the fix; RED step must be run and confirmed failing for the documented reason before GREEN. |
| Guard exists but call graph is incomplete | `refuse_if_outside_root` was correct and wired into exactly one caller (draft), leaving `apply` unguarded. The bug was never in the guard. | blocking | Enumerate every write branch and route them through a single choke point; assert the choke point is the sole call site. |
| Derived-plane snapshot pair drift | Phase 27's plan 27-02 regenerated `.memory/derived/contracts-index.md` but not `tools/memory_regen/tests/__snapshots__/test_contracts_index.ambr`, leaving a red gate the next plan inherited and deferred. | advisory | Any contract change commits BOTH derived artifacts together; run `uv run pytest tools/memory_regen -q` before committing, not after. |
| Executor reaching for destructive git | Plan 27-03's executor ran `git stash -u` + `git checkout <old-commit> -- .` while investigating a red test, briefly reverting 4 files. Recovered, no commit lost. | advisory | Executor prompts carry an explicit destructive-git prohibition; on unexpected repo state, STOP and report instead of self-recovering. |
