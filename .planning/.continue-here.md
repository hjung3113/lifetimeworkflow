# BLOCKING CONSTRAINTS — Read Before Anything Else

> Not suggestions. Each was discovered through actual failure during the v2.6 session.

- [ ] CONSTRAINT: **pytest is not the gate.** `uv run pytest` passing does NOT mean the tree is green.
  This session reported "gate green" several times off pytest alone; CI then failed on
  `tools.ruff_baseline` with 23 violations v2.6 had introduced (E501 +19, B905 +2, I001 +2), turning
  PR #7 red after the milestone had already been declared closed.
  **Structural mitigation:** before claiming green or handing off, run
  **`uv run python -m tools.ruff_baseline`** alongside the suite — or run `/verify-work`, which already
  composes lint + tests + contract validation + derived freshness, and which the phase executors never
  actually went through.

- [ ] CONSTRAINT: **verification ≠ review.** Four adversarial review passes found **8 critical defects
  in code whose phase VERIFICATION.md already read `passed`** — including a `../../`-traversal contract
  path that resolved onto the real contract's node and returned confident output, and a skill that
  walked an agent author into a guaranteed guard failure.
  **Structural mitigation:** never close a phase on verification alone; run the review step and fix
  what it returns.

**Do not proceed until both boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| In-session gate ≠ CI gate | Ran pytest only; the ruff ratchet regression reached CI unnoticed and reddened PR #7 | blocking | Run `uv run python -m tools.ruff_baseline` (or `/verify-work`) before any green claim or handoff |
| Verification passes over real defects | Phase verifications returned `passed` 4/4 while review found 8 criticals in the same code | blocking | Keep the adversarial review step; verification is not sufficient to close a phase |
| Live-tree tests that prove nothing | The contract graph is EMPTY here (`{"relationships": [], "adjacency": {}}`), so an `/impact` traversal test against the live tree would pass while proving nothing | advisory | Synthetic fixtures are mandatory where the live tree cannot exercise the behaviour — now encoded in `tools/contract_graph/tests/test_impact.py` |
| Live-tree snapshots under `tools/` break GEN-04 | A syrupy snapshot of the real tree embedded `examples/log-parser/...` paths under `tools/`, tripping the core-no-example-dep guard | advisory | Snapshot only hermetic `tmp_path` fixtures; fixed in `tools/memory_regen/tests/test_package_facts.py` |
| Per-task auto-commit breaks atomicity | Plan 50a-01's prose said "one commit", but executors commit per task — which would have committed a skill set that cannot regenerate (`validate.check_skill_set` raises before any write) | advisory | When a change has no valid intermediate state, merge the tasks into one before executing |
| Assertions satisfied by rewording | Several structural gates keyed on substrings that unrelated prose elsewhere in the same file could satisfy | advisory | Scope predicates to the section they govern; mutation-test every new or edited assertion in both directions |
