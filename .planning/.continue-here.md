# Carry these into v2.6 — both were discovered by failure, repeatedly

- [ ] **A check that cannot fail.** Six instances across phases 40–46 passed while the thing they
  guarded was absent; two more were found during the milestone close itself (phases 43–46 sat
  unchecked in ROADMAP while the Progress table read Complete; CER-01/02/03 read `Not started`
  against a VERIFICATION recording all three SATISFIED). The normal gates verify that declared
  things *exist*, never that declarations still *mean* something.
  **Mitigation:** mutation-test every new or edited assertion — break what it guards and confirm it
  REDs before committing. Scope predicates to the section they govern; count per-block, never
  whole-file.

- [ ] **Never forge a human-ratification token.** `GOLDEN_APPROVE_HUMAN` must never be set by an
  agent, and `HARNESS_DEV_BYPASS` must not be used to edit a plane a gate protects.
  `CONSTITUTION_GLOBS = ["contracts/**", "docs/adr/**", "docs/glossary.md"]` — **`docs/adr/**` is on
  it**, so authoring an ADR is human-gated exactly like the glossary. The working pattern when an
  agent must not write: prepare the edit as a script off-plane, with each replacement asserting an
  exact single match, and have the human run it (`.planning/quick/260729-wdi-*/apply.sh` is the
  worked example). A path around a gate is a **reportable defect, never a shortcut**.
