## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Claimed-but-untested invariant | `inject.py:20-22` asserted "delete+regen identical" in prose while **no test anywhere** asserted it. The ROADMAP then said SC2 "preserves" determinism — you cannot preserve what was never enforced. Research caught this; it would otherwise have shipped as a phantom guarantee. | blocking | When a Success Criterion says an invariant is "preserved", **grep for the test first**. If absent, building the net is Wave 1 work, not an assumption. |
| `_TEMPLATE.md` ships `status: active` | A naive `glob("*.md")` over `.memory/agreements/` injects the template body (`<One-line working-style or methodology rule.>`) as a **live priority-0 directive**. | blocking | 3-layer fail-closed exclusion: `status == "active"` only, `_`-prefix excluded, `README.md` excluded. Covered by `test_only_active_non_template_agreements_compose`. |
| Substring-matching a gate | A naive `grep -i date` for the no-wall-clock check **false-passes**: `memory-inject.sh:4` contains `gsd-check-update.js` → matches "up**date**". The planner caught this; the original research did not. | advisory | Gates use command-shaped tokens (`$(date`, backtick-date, `^\s*date\b`), never the bare word. |
| Unsorted `glob()` as a determinism hole | `glob()` returns **filesystem order**, not sorted. Composing a directory without `sorted()` makes the payload environment-dependent and byte-identity non-reproducible. | advisory | Explicit `sorted()`; fixture creates files in **non-alphabetical** order so the test is falsifiable rather than vacuous. |
| Memory drift vs. recent feedback | Memory `execute-via-codex-orca` said Codex model = **luna**, but the Phase 17 handoff recorded the user rejecting luna as too expensive and switching to **terra**. The memory was never updated → the conflict resurfaced this session. | advisory | Memory **fixed** (luna → terra) + the MCP-stall failure mode recorded. When a handoff contradicts a memory, update the memory rather than re-asking. |
| GSD gate silently skipped on format mismatch | The §13a decision-coverage gate returned `passed: true, skipped: true, "no trackable decisions"` — because `13-CONTEXT.md` writes decisions as `**D-01**:` (bold), which the parser does not recognize. The gate **did not actually assert** D-01..D-20 coverage; the plan-checker verified it manually instead. | advisory | Do not read `passed: true` as "verified" when `skipped: true` accompanies it. If Phase 14 wants machine-tracked decisions, match the parser's expected `D-NN` format. |
| `tui-idle` false positive | `orca terminal wait --for tui-idle` reported `satisfied: true` while Codex was still actively working (spinner running). Waiting on it alone would have caused a premature "done" read. | advisory | Poll on **commit count** / real artifacts, not just TUI idle. |
| Crude keyword gates misfire | The plan-phase §5.6 UI gate matched `ui` inside "g**ui**delines" and would have generated a UI design contract for a Python injector. §4.5 likewise matched "agent" inside "agent-side". | advisory | Judge the phase's actual substance, not the grep. Both gates were consciously skipped and the reason recorded. |
