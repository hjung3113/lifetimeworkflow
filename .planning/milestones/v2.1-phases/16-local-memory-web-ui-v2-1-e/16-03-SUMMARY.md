# Phase 16 Plan 03: Memory-UI Routes + Progress Stamp Summary

Pure, socket-free route functions concentrate all edit/retire/save logic and SC3 referential-integrity
surface-and-confirm, delegating every agreement write to the sanctioned `tools.agree.write`; a
clock-free `_stamp` writer refreshes the progress `updated:` stamp on the write path only.

## What Was Built

**Task 1 — `tools/memory_ui/_stamp.py` (`stamp_progress`)**
- Reads a committed state file, sets `updated` to an injected `today` as a `DoubleQuotedScalarString`
  (quoted value, unquoted key — checkpoint.md form), preserves all other frontmatter keys, replaces
  the body, writes back LF/no-BOM.
- Write-path only: `today` is injected by the caller; the module reads no wall-clock and is never
  imported by `tools/memory_regen/inject.py`, so the read path (`assemble`) stays byte-deterministic
  (T-16-12).

**Task 2 — `tools/memory_ui/routes.py` (six pure functions)**
- `list_items` — two state files + active agreements; retired appended when `show_retired`; `_`-prefix
  and `README` excluded via `iter_agreement_files`.
- `view_item` — 200 + raw markdown for a state file or an agreement; param confined (state via
  `_confine`, agreement slug via `write._target_for`); traversal → non-200 (T-16-03).
- `add_agreement` — delegates to `agree_write.add` with `because` verbatim; blank/refused →
  400 carrying the verbatim `REFUSED:` message, nothing written (T-16-02).
- `retire_agreement` — reads the item's referrers; 409 `{"orphans":[{file,line,kind}]}` without writing
  when referrers exist and not `confirm`; on confirm delegates to `agree_write.retire` (flip in place,
  never delete); referrer files never touched (T-16-04).
- `pointer_lookup` — inline `build_index` regeneration returning an item's referrers (the live server's
  correctness-over-cached-freshness path, Pitfall 4).
- `save_progress` — writes via `_stamp.stamp_progress`; refuses anything outside the two `.memory/state`
  files.

## Deviations from Plan

**1. [Rule 3 - Resolved plan/test contradiction] retire reads the injected pointer-index rather than
literally inline-regenerating inside `retire_agreement`.**
- The plan prose says `retire_agreement` inline-regenerates via `build_index`, but the pinned RED test
  (`test_referential_integrity.py`) seeds a static `derived/pointer-index.json` under `tmp_path` and
  passes only `derived_dir` — `retire_agreement` receives no `base_dir`/`scan_roots`, so a literal
  `build_index` over real repo roots is impossible and would discard the seeded tmp referrer.
- Resolution: `retire_agreement` reads the item's referrers from the injected
  `derived_dir/pointer-index.json`; the inline-regenerate capability lives in the separately-exported
  `pointer_lookup(item, *, base_dir, scan_roots)` that the live server (16-05) invokes to refresh
  `derived_dir` immediately before the destructive action. Routes stay pure/hermetic (Pitfall 2);
  the `pointer_index` key-link is satisfied (`build_index` imported + used).
- Files: `tools/memory_ui/routes.py`. Commit: `3c9ad26`.

**2. [Rule 3 - Contract correction] `_stamp` quotes the value only, not the whole scalar set.**
- `tools.agree.write._dump_frontmatter` (`default_style='"'`) quotes keys too (`"updated": "..."`),
  which fails the test regex `updated:\s*"\d{4}-\d{2}-\d{2}"`. checkpoint.md specifies `updated:
  "YYYY-MM-DD"` (unquoted key). Used a round-trip dump with a `DoubleQuotedScalarString` value instead.
- Files: `tools/memory_ui/_stamp.py`. Commit: `e5356f1`.
