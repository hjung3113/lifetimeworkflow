## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| network → HTTP server | the bind address is the only access-control boundary (no auth by design) |
| browser page → external internet | the page must fetch nothing off-origin |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-05 | Info Disclosure/Elevation | binding beyond loopback exposes the tool | mitigate | Hardcode `("127.0.0.1", port)`; no `--host` flag; test asserts loopback bind; never `0.0.0.0`/`""` |
| T-16-06 | Tampering | page fetching external assets (supply-chain / exfil) | mitigate | Single inlined page; no CDN/web-font/external URL; test greps `PAGE` for `http(s)://` |
| T-16-07 | DoS | unbounded POST body to the handler | mitigate | Size-bound the request body before JSON-parse in the handler |
| T-16-14 | Tampering | DNS-rebinding / cross-origin POST to the local server | accept | Low risk for a single-user local tool; optional `Host: 127.0.0.1/localhost` check is executor discretion (UI-SPEC/RESEARCH) |
| T-16-SC | Tampering | pip/uv installs | accept | Zero external packages (stdlib `http.server`); no lock change |
