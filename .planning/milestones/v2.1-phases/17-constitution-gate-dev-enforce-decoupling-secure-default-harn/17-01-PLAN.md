<objective>
Implement the approved secure-default dev opt-out `HARNESS_DEV_BYPASS` for the two constitution
gates, with tests covering every Success Criterion in 17-CONTEXT.md. One shared `dev_bypassed()`
helper in `tools/hooks/_stdin.py`, threaded into `contract_guard.main()` (access-control deny waived,
distinct dev-note) and `commit_gate.check_drift()` (DRIFT-ONLY downgrade, distinct dev-note). Byte-
hygiene (§4.3-4.6) is NEVER waived; the default (unset/blank/whitespace) stays enforce.

enforcement anywhere else — the runtime half of the posture ADR-0007 (plan 17-02) records.

`uv run pytest tools/hooks`.
