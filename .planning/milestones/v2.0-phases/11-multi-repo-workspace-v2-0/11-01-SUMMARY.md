# Phase 11 Plan 01: Workspace Manifest + Loader + Consistency Gate Summary

Raised the GEN-03 config-slot pattern one level into a pure-DATA `workspace.toml` multi-repo
manifest, a `tools/workspace_config` stdlib-`tomllib` passthrough loader, an MREPO-01 consistency
gate, and a fully-baselined 2-member in-repo fixture that turns the Wave-2/3 gates green.

## What Was Built

- **`workspace.toml`** (root, pure DATA): `[workspace] id = ""` generic default, two `[[members]]`
  (id + repo-relative root inside `tests/fixtures/workspace/`), one `[pipeline].edges`
  `{ from = "member-a:emit", to = "member-b:ingest", contract = "greeting" }`. Header comment names
  its two consumers; a commented `# url =` seam marks remote roots as a deferred milestone.
- **`tools/workspace_config`** virtual uv member (mirrors `tools/harness_config`): `load_workspace`
  (binary `tomllib.load`, `parents[2]` anchor), `members()`/`edges()` passthrough, and
  `split_endpoint("repo:stage") -> (repo, stage)` (bare stage → `(None, stage)`, backward-compatible).
  PEP 562 lazy re-export `__init__`. Loader hardcodes no member path (GEN-04-clean). Registered in
  `uv.lock` via `uv sync --all-packages` — only the in-repo member, zero external deps.
- **`tools/harness_lint/tests/test_workspace_config.py`** — MREPO-01 gate: member-id uniqueness,
  each member root `.exists()`, every edge endpoint resolves (via `split_endpoint`) to a declared
  member (no dangling), each edge contract tracked under the PRODUCER member's `contracts/**` via
  `rglob`, and a visible `pytest.skip` on a zero-edge workspace (never a silent pass).
- **2-member fixture**, fully baselined: both members carry a `greeting` contract; each has its own
  self-relative `contracts/.hashes/manifest.json` (generated by `contract_hash`, not merged); one
  identity-converter golden case (`greeting-edge`) whose seed→baseline diff is R8 row-order only, so
  it PASSes with no .NET.
