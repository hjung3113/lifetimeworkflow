Reference generator idiom to clone (source: `tools/memory_regen/contracts_index.py:19-33,105-127`,

```python
from __future__ import annotations
import sys
from pathlib import Path

_REPO_ROOT = Path(__file__).resolve().parents[2]
DERIVED_DIR = _REPO_ROOT / ".memory" / "derived"
INDEX_PATH = DERIVED_DIR / "contracts-index.md"
DERIVED_HEADER = "DERIVED — do not hand-edit (tools/memory_regen/contracts_index.py)"

def write(index_path=INDEX_PATH, ...) -> Path:
    out = Path(index_path)
    out.parent.mkdir(parents=True, exist_ok=True)
    out.write_text(render(index_rows(...)), encoding="utf-8")
    return out

def main(argv=None) -> int:
    out = write()
    rows = index_rows()
    print(f"wrote {out.relative_to(_REPO_ROOT)} ({len(rows)} contract(s) indexed)")
    return 0

if __name__ == "__main__":
    raise SystemExit(main())
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| git-tracked manifest content → generator | `build_facts()` reads only this checkout's own git-tracked manifest files; no external/network input. |
| dependency reference (path-based) → filesystem resolution | A `.csproj`/`Cargo.toml` path reference is normalized and matched against KNOWN package manifest paths only — never used to open an arbitrary file. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-47-02-01 | Tampering | `build_facts()` path-based edge resolution | mitigate | A normalized path reference is matched against the closed set of already-discovered manifest paths (a dict lookup) — never used to `open()`/`read_text()` an arbitrary filesystem path, so a crafted `../../../etc/passwd`-style `Include` value simply fails to match any known manifest and the dependency is dropped, not followed. |
| T-47-02-02 | Tampering | `git -C <repo_root> ls-files` subprocess call | mitigate | `shell=False`, argument list (no string interpolation), `check=True` so a non-zero exit surfaces as an exception rather than a silently empty result — mirrors the existing `test_core_no_example_dep.py`/`scan.py` git-invocation idiom. |
</threat_model>
