## Shared Patterns

### Derived-artifact idiom (applies to `package_facts.py` + its test + `.gitignore` + `ci.yml`)
**Source:** `tools/memory_regen/contracts_index.py` (full file) + `.gitignore:20-27` + `ci.yml:259-299`
**Apply to:** `package_facts.py`, `test_package_facts.py`, `.gitignore`, `ci.yml`
- `DERIVED — do not hand-edit (<generator path>)` header as line 1 of every rendered artifact.
- No timestamp, no raw float — byte-identical regeneration is a hard determinism guarantee, proven by a `hashlib.sha256` delete+regenerate test (`test_contracts_index.py:71-80`), not `git diff` (that pattern is for the *gitignored* `contracts_index.md`'s own historical state — `package-facts.md` is committed from day one, so it additionally needs the `.gitignore` re-inclusion + `stale-derived` regen/diff wiring that `contracts_index.md` only gained later per phase 09-02).
- Rows sorted deterministically before render — never raw dict/set iteration order.

### Sibling-function-not-signature-change idiom (applies to `detect.py` and `loader.py`)
**Source:** `detect.py`'s own function-ladder shape (`detect_languages`, `detect_manifests`, ... each independent, same module) + `loader.py`'s `components()`/`pipeline()`/`effective_relationships()` (each independent, same module, same "load default if omitted" convention)
