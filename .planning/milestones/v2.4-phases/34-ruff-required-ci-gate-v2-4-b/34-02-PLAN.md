<objective>
Build the ratchet: a committed per-rule baseline plus a CLI that fails when any rule's count goes
up, and that cannot be used to raise the baseline.

Purpose: the 400 genuine findings must be *held* — the requirement forbids both mass-fixing them
and blanket-ignoring them. A ratchet is the only mechanism that makes "can only shrink" an
executable claim rather than a norm.

Output: `tools/ruff_baseline/` as a virtual uv workspace member, its hermetic test table, and
`baseline.json` recording 400.
</objective>

    - identical -> ok
    - a rule DECREASED -> ok (and the result reports the shrink)
    - a rule INCREASED by 1 -> NOT ok, and the failure message names that rule code with both numbers
    - a rule code present in `current` but ABSENT from `baseline`, count 1 -> NOT ok (D-05: absent means 0)

    - one rule up, another down by the same amount -> NOT ok (the *rule* is the unit, not the total)

    - empty baseline + empty current -> ok
    - empty baseline + any finding -> NOT ok

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| ruff subprocess -> gate verdict | a failed or mis-resolved ruff must not be readable as "clean" |
| baseline file -> gate verdict | the file the gate compares against is writable by the same agents it gates |
| ruff cache state -> gate verdict | a local filesystem artifact must not be able to change the verdict |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-34-04 | Spoofing | `ruff` resolved from `PATH` | mitigate | `sys.executable -m ruff` — the interpreter the workspace already selected, never an ambient binary |
| T-34-05 | Tampering | `--update` used to absorb a regression | mitigate | `write_baseline` refuses on any increase (exit 3) and leaves the file byte-unchanged; tested |
| T-34-06 | Repudiation | a silently green gate after a broken invocation | mitigate | returncode not in (0, 1) raises; monkeypatched-subprocess test row asserts it |
| T-34-07 | Tampering | a warm-vs-cold verdict split between local and CI | mitigate | `--no-cache` always, with the reason in a comment and in RESEARCH §1.0 |
| T-34-08 | Elevation of Privilege | a new rule class absorbed silently | mitigate | absent-from-baseline means 0, so first appearance fails; tested |
| T-34-SC | Tampering | npm/pip/cargo installs | mitigate | `dependencies = []`; `uv.lock` asserted unchanged |
</threat_model>
