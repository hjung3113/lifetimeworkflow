<objective>
Reach a recorded, evidence-backed disposition for `DEF-05-02-1` — the three `commit_gate`
drift-block tests recorded as leaking an ambient `GOLDEN_APPROVE_HUMAN` token.

Purpose: this item may already be repaired. The requirement is that the record ends up **accurate**,
not that a fix is applied. Applying the record's suggested fix without checking would be the failure
mode, not the deliverable.

Output: an accurate `DEF-05-02-1` record, and a reported STATE.md delta.
</objective>

## Tasks

### Task 1 — Reproduce, both ways

Locate the three tests the record names. Run them with the token unset and with it exported:

```
env -u GOLDEN_APPROVE_HUMAN uv run pytest <the 3 tests> -q
GOLDEN_APPROVE_HUMAN=<any-value> uv run pytest <the 3 tests> -q
```

<automated>
Both runs recorded verbatim with their counts. Branch on the result:
- **reproduces** -> Task 2a
- **does not reproduce** -> Task 2b
</automated>

### Task 2a — (only if it reproduces) Fix and prove

Add `monkeypatch.delenv("GOLDEN_APPROVE_HUMAN", raising=False)` per the record's suggestion; re-run
both ways and show both green.

### Task 2b — (only if it does not reproduce) Establish WHY

Find the repairing commit (`git log -S` on the relevant symbol). Read its message and diff. Then
**prove causality by mutation**: neuter the repair and re-run with the token exported. The recorded
symptom must return exactly — the three named tests and no others. Revert the mutation; confirm the
tree is clean.

<automated>
`git log -S'<symbol>' -- tools/hooks/tests/test_commit_gate.py` returns the commit; the mutation run
fails exactly the three named tests; `git status --short tools/hooks/` is empty after revert.
</automated>

### Task 3 — Close the record

Write the disposition into `.planning/phases/05-despecialization/deferred-items.md`: status, the
repairing commit or the fix, the both-ways table, and the mutation evidence. Do **not** edit
`.planning/STATE.md` — report its delta instead.

<automated>
`grep -c RESOLVED` on the record > 0; `git status --short .planning/STATE.md` is empty.
</automated>
