**Status:** ✅ SHIPPED 2026-07-30

**Net effect (excluding `.planning/`):** 385 files, +3,115 / −30,513 = **net −27,398 LOC**

## Overview

The harness had grown machinery to verify itself. This milestone made **CI and the merge** the
authority instead (ADR-0012), deleted the self-verification stack, and repaid the product side.

Seven phases removed; the eighth added. The gates a human must personally **author** went from five
kinds to **zero**. The constitution plane narrowed from four members to three by ratified decision
(ADR-0012 clause (d)). The deployed product gained four routes plus `/flow` — commands 17 → 18, with
`+0` on every other surface count.

Most of the effort went not into deleting but into **proving the deletions safe**. Every phase
shipped green and still left declarations that had quietly stopped meaning anything, which is why
this milestone's defining lesson is about checks that cannot fail rather than about stale references.

## Closing evidence

CI ran on this work for the first time at the milestone-close PR (#5) — `ci.yml` is
`pull_request`-only and this repo does one PR per milestone, which is why Phase 43's SC-1 could not
be satisfied in-repo. All 11 jobs plus the `gate` fan-in passed. PR #6 then closed the four
human-gated leftovers (ADR-0013, the two glossary rows, the README test counts, and the D-24
decision) and passed the same fan-in.

Final gate state: core **881 passed / 7 snapshots**, instance **14**, `contract-drift` (core +
workspace), `emit-drift`, `stale-derived` and the ruff ratchet all exit 0.

**Key decisions**

- **Removed `golden/**` from the constitution plane** rather than repointing it at the relocated
  baselines. ADR-0012 clause (d) had already superseded ADR-0001's four-member list and explicitly

- **Deleted `commit_gate`'s golden-parity component** as a recorded CER-09 scope extension: a
  pre-commit golden-parity check is exactly the in-session gate ADR-0012 replaces.
- **Corrected Phase 44's SC-5 rather than deleting `format_on_write::resolve_dotnet`** — shelling
  `dotnet format` is a language-toolchain concern legitimate in a polyglot core, not .NET *parity
  evidence*, which is what ADR-0002(b) puts in the instance.
- **Recorded Phase 44's SC-6 as NOT MET AS WORDED** rather than narrowing the criterion. Narrowing an
  over-matching proxy is legitimate; restating a criterion to match an observation is not.

  work had shipped in `45364d7` with no VERIFICATION.md and CER-04 left unchecked while fully
  satisfied.

  after three reading passes in Phase 43 each declared the defect set closed and were each wrong.
- **Accepted D-24 — CODEOWNERS is advisory here — as a documented residual** (owner, 2026-07-29).
  `require_code_owner_reviews=true` cannot be satisfied in a solo repo because GitHub forbids
  self-approval; adding a compensating in-session control is the ceremony ADR-0012 and ADR-0013
  clause (c) rule out.

**Defect classes this milestone surfaced** (both now in durable memory)

1. **A check that cannot fail.** Six distinct instances across phases 40–46, every one passing while
   the thing it guarded was absent: `RETIRED_SIGNATURES[0]` reading only entry 0; a test asserting
   `[] == []`; a loop over an emptied `edges` list; `*.env` deny rows asserted green after
   `secret_scan`, their only enforcer, was deleted; `CONSTITUTION_GLOBS` keeping `golden/**` after
   the baselines moved (all 7 globs matching nothing); and three Phase-46 predicates passing on prose
   elsewhere in the same file. The normal gates verify that declared things *exist*, never that
   declarations still *mean* something. Mitigation: mutation-test every new or edited assertion;
   scope predicates to the section they govern; count per-block, never whole-file.
2. **Live-tree-rendering artifacts repaired late.** A committed test, snapshot, frozenset or count
   that renders the live tree, invalidated by a change and named by no plan. Phases 43–45 produced
   twenty-plus instances; `pytest --collect-only` sees none of them. Direction-agnostic — Phase 46
   *added* a command and hit the identical set. Mitigation: repair each in the **same commit** as the
   change that invalidates it.
