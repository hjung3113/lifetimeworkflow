- `compile_graph(cfg=None) -> {"relationships": [...], "adjacency": {authority: [sorted dependents]}, "diagnostics": [...]}`.
  Queries operate on the `"adjacency"` dict only.

Cycle-safe traversal pattern (research Pattern 2 — iterative worklist, NOT recursive):
```
visited = {start}
paths = {start: [start]}
frontier = [start]
while frontier:
    node = frontier.pop(0)
    for nxt in adjacency.get(node, []):
        if nxt in visited:
            continue  # cycle terminus — never re-enqueue, never recurse
        visited.add(nxt)
        paths[nxt] = paths[node] + [nxt]
        frontier.append(nxt)
```
This exact shape (visited-set checked BEFORE enqueue) is the termination guarantee for `transitive()`
and is reused by Plan 03's indented-tree renderer for the `(cycle → <node>)` marker.
