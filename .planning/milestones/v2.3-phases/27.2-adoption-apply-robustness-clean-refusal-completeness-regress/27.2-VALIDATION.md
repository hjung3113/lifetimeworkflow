## Sampling Rate

- **After every task commit:** the task's own selection (see the Automated Command column) — never
  the full suite, because the co-tenant plan leaves other files in this package deliberately RED
  mid-plan
- **After both wave-1 plans land (phase-closing fan-in):** `uv run pytest -q`,
  `uv run python -m tools.contract_drift.drift`, `uv run python -m tools.harness_emit` +
  `git status --porcelain`, `uv run pytest tools/harness_lint -q`
- **Max feedback latency:** ~6 seconds (single-file selection), ~90 seconds (full suite)

> **Execution trap recorded by this phase (27.2-01-PLAN.md:279-282).** The RED gate is written
> `! uv run pytest ...` on purpose — it exits 0 only when the selection genuinely fails. But an
> inverted gate **also** exits 0 on a collection/import error, which is not a RED, it is a broken
> run. Run RED selections plain and read the output; passes reported alongside failures are the
> proof that collection succeeded.
