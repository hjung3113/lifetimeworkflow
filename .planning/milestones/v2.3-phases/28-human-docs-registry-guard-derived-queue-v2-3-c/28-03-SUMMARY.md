# Phase 28 Plan 03: DOCSUP-01 Registry Validation Summary

`load_registry` validates `docs/doc-dependencies.toml` against the constitution-plane schema and
then enforces the five DOCSUP-01 semantic rejections the schema provably cannot express — proven
per-class by a 21-row adversarial table that was RED against a shape-only validator first, with a
paired 6-row negative control pinning "did not over-refuse" before any rejection landed.

## What Was Built

**`tools/docs_guard/registry.py`** — `load_registry(path=DEFAULT_REGISTRY_PATH, root=REPO_ROOT)`
returning a `list[Binding]` sorted by `id`, plus `RegistryError(ValueError)`. Order is load-bearing:

1. Parse — missing file returns `[]` (missing != invalid; only invalid maps to 28-05's exit 3).
   `tomllib.TOMLDecodeError` becomes `RegistryError`, never a raw traceback.
2. SHAPE — `Draft202012Validator` against `contracts/harness/docs/doc-dependencies.schema.json`,
   located by a path resolved from `__file__` (never CWD). ALL `iter_errors()` emitted at once,
   sorted by `json_path`.
3. STRUCTURAL path escape — absolute spelling or a literal `..` SEGMENT, refused **before any
   `Path.resolve()` or filesystem call**. Segment-wise, never substring, so `a..b.py` stays valid.
4. RESOLVE-THEN-CONFINE backstop — `refuse_if_outside_root`, which is what catches the symlink row.
5. Duplicate id — `loader.py:149-160`'s sorted-diagnostic block.
6. Empty selector, CONDITIONAL on `severity == "required"` (an `advisory` row with no sources is
   valid — this is why the schema omits `minItems`).
7. Derived target — matched against the **imported** `DERIVED_GLOBS` using the repo's existing
   `resolve_path` glob resolver; no new matcher, no second copy of the list.
8. Accepted-ADR policy (D-09), including the `- **Status:**` parse and the reverse partition.

**`tools/docs_guard/tests/test_registry.py`** — `REJECTION_CASES` (21 rows: 5 path-escape spellings,
1 duplicate id, 1 empty-required, 8 derived targets **generated by iterating the imported
`DERIVED_GLOBS`**, 6 ADR-policy rows), `VALID_CASES` (6 negative controls), the Class A zero-read
spy, the sorted-duplicate-diagnostic pin, the no-content-leak probe, and a writes-nothing assertion.

## Deviations from Plan

**1. [Rule 1 - Bug] Class A read-spy was built on an unpatchable idiom**

- **Found during:** Task 2 (first GREEN run)
- **Issue:** The spy used `MagicMock(wraps=Path.read_bytes)` / `MagicMock(wraps=Path.read_text)`.
  Patching an UNBOUND method on `Path` with a mock drops `self`, so the spy raised
  `TypeError: Path.read_text() missing 1 required positional argument: 'self'` — the test failed
  instead of observing anything. A second defect: the anchor assertion only spied `builtins.open`,
  but `load_registry` opens the registry via `Path.open`, so the spy could have passed vacuously.
- **Fix:** Replaced the mocks with hand-rolled wrapper functions that record the path and delegate
  to the captured original, added `Path.open` to the spy set, and added a positive anchor
  (`str(path) in read_paths`) so a spy that observes nothing at all cannot pass.
- **Files modified:** `tools/docs_guard/tests/test_registry.py`
- **Commit:** `c5f60f6`

No other deviations. This affected the spy harness only; the five rejection classes and their RED
evidence are unchanged.
