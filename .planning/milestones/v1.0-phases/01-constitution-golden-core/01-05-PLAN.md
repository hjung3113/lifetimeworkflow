<objective>
Build the contract-drift gate (CONTRACT-04): canonicalize every `.schema.json` with RFC 8785 (JCS), SHA-256 it into a manifest, and fail when the live manifest diverges from the committed baseline — classifying the change breaking vs non-breaking. This is the SECOND canonicalizer and it is entirely separate from the §4-5 TSV comparator: JCS runs on JSON contract TEXT, is Python-only (`rfc8785` 0.1.4), and needs zero .NET code. Crucially the hash covers `format-conventions.schema.json`, closing the P14 hole so a §4-5 convention change trips the gate exactly like a column reorder.

Purpose: The schema is the source of truth (D-06/D-07); unapproved contract change must fail loud, and the drift signal must include cross-cutting conventions, not just columns (P14).
Output: tools/contract_hash + tools/contract_drift + committed baseline manifest + mutation/classification tests.
</objective>
