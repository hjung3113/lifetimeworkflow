# Adversarial Review Templates

## Review charter
Target, objective, definition of done, risk rationale, observed Evidence Pack, unknowns, scope, non-goals, decision criteria, selected experts.

## Design final
Verdict; direction; system boundaries; major decisions; rejected alternatives; critical unknowns; required reinforcement; verification strategy; residual risk.

## Code/document final
Verdict; requirement alignment; correctness; maintainability; missing evidence; scope creep; required/recommended/optional reinforcement.

## Debug final
Confirmed diagnosis evidence; fix boundary; affected callers/data paths; regression seam; blast radius; rollback; architecture follow-up; residual uncertainty.

## Refactor final
As-is; current cost; to-be; explicit scope; expand/migrate/contract stages; compatibility; stage verification; rollback/pause points; non-goals.

## API/data final
Contract delta; compatibility; schema/data migration; integrity; security/privacy; rollout; rollback; verification.

Each review workspace contains authoritative FINDING_TEMPLATE.md, CHALLENGE_TEMPLATE.md, and FINAL_TEMPLATE.md for agent-to-agent exchange.
