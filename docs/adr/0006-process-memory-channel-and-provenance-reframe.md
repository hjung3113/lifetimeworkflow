# 6. Memory Model: PROCESS/Agreements Channel + Provenance→Data-Authority Reframe

*MADR 4.x · plane: constitution (human-owned, immutable, append-only)*

- **Status:** accepted
- **Date:** 2026-07-14
- **Deciders:** operator-delegated, MEM2 kickoff decisions Q1–Q6
- **Supersedes:** —
- **Superseded by:** —
- **Complements:** [ADR-0002](0002-general-template-de-specialization.md) (core is domain-neutral) — the agreements tier holds domain-neutral working-style guidance, not instance data; the two-plane memory boundary this ADR extends is declared in `.memory/README.md`.

## Context and Problem Statement

The harness's context memory (`.memory/`) shipped as a **two-plane** model — a human-owned
CONSTITUTION plane (`contracts/`, `docs/adr/`, `golden/`) and a machine-owned DERIVED plane
(`.memory/derived/`), plus a small committed STATE tier (`.memory/state/`) for volatile agent hints.
The MEM2 milestone (`.planning/MEMORY-UPGRADE-PROPOSAL.md`) surfaced two gaps this decision records:

- **§7b — no home for working agreements.** User feedback about *how to work* in this repo (methodology,
  working-style guardrails) had nowhere durable to live. It is not a project/architecture decision
  (those belong in `docs/adr/` + `PROJECT.md` Key Decisions), it is not volatile session state, and it
  is not derived. It kept dissolving into tribal knowledge — the exact failure the harness exists to
  prevent.
- **§7c — the STATE framing over-claimed distrust.** The session-start state surfaces told an agent its
  own grounded work was *"a hint, not truth"* / *"provisional, confirm before trusting."* That framing
  is an **epistemic** distrust of the agent's own findings, when the real rule is narrower: it is a
  **data-authority precedence** rule — when two sources disagree about DATA, `contracts/` + `docs/adr/`
  win. Framed as blanket distrust, it taught agents to discard sound grounded context.

Both needed to be recorded as a point-in-time model change, not silently patched, because they alter
what planes the memory model has and what the state surfaces assert.

## Decision Drivers

- **Working agreements are a distinct ownership class.** Committed (survives sessions), human-authored
  via feedback, curated — but *not* constitution (not path-denied) and *not* derived (never
  regenerated). None of the three existing planes fit; forcing it into one would blur an ownership
  boundary the harness depends on.
- **LINK-not-restate keeps ADR/decisions the single source (§7c).** An agreement must reference a
  decision, never duplicate it — a restated decision is a second source that drifts.
- **Precedence ≠ distrust.** The data-authority rule must still be stated (contracts/ + docs/adr/ win a
  DATA conflict) without instructing the agent to discard its own grounded, non-conflicting work.
- **Machines gate, humans ratify.** This ADR itself lands only via the human-gated constitution path —
  it is the worked example of the rule it records.

## Considered Options

1. **Reuse `.memory/state/` for agreements.** *Rejected:* STATE is volatile agent-authored hints;
   agreements are curated human feedback meant to persist and be retired-not-deleted. Different
   ownership + lifecycle; co-locating them erases the boundary.
2. **Put agreements under the CONSTITUTION plane (`docs/adr/` or a gated dir).** *Rejected:* working-style
   guidance is not an architecture decision and must stay agent-writable-via-feedback; path-denying it
   would block the `/agree` write path (Phase 14) and conflate methodology with ratified decisions.
3. **Add a 4th committed PROCESS tier `.memory/agreements/` + scope the distrust framing to
   data-authority (chosen).** A new non-constitution, non-derived committed plane holds one
   `<slug>.md` per guideline; the five state/memory surfaces are reworded from "provisional/distrust"
   to an explicit data-authority precedence rule.

## Decision Outcome

**Chosen: Option 3**, in two parts:

**(a) Fourth plane — committed PROCESS/agreements tier.** `.memory/agreements/` is added as a
**committed, human-authored, curated** tier (the D-Q1 *committed-but-writable* posture for MEM2-01).
It is **not derived** (never regenerated by `tools/memory_regen`, does not collide with
`.memory/derived/`) and **not constitution** (not path-denied). Each working guideline is one
`<slug>.md` from [`_TEMPLATE.md`](../../.memory/agreements/_TEMPLATE.md): YAML frontmatter carries
`status:` (`active`/`retired`), `added:` (ISO date), and `provenance:` (`"added because <verbatim
user feedback>"`); the body carries a title, a one-line working-style/methodology rule, and a
`Related:` link that **links to — never restates —** the governing ADR / PROJECT Key Decision (§7c).
Agreements are **retired (`status: retired`), never deleted.**

**(b) Provenance→data-authority reframe.** The five session-start/memory surfaces no longer frame the
agent's own grounded work as untrustworthy. Each reworded surface **still states the data-authority
rule** — on a DATA conflict, `contracts/` + `docs/adr/` win — but drops the blanket
"provisional/confirm-before-trusting/a hint, not truth" epistemic framing.

**(c) Scope + deferred work.** This ADR records the model change and the scaffold. The **`/agree`
write path + provenance lint** land in **Phase 14**; the **runtime emit** of the reworded
`two-plane-memory` skill to both runtime trees is deferred to **Phase 15** (source edited now, emit
later). The `contract-guard` runtime enforcement that gates this very ADR is the Phase-4 hook
(already live), which is why an agent could not land 0006 itself.

### Consequences

- **Good:** working-style feedback has a durable, curated, provenance-stamped home instead of
  dissolving into tribal knowledge; retire-not-delete keeps the guidance history auditable.
- **Good:** the state surfaces stop teaching agents to discard their own sound context while keeping
  the real precedence rule intact — fewer false "I can't trust this" stalls.
- **Good:** the LINK-not-restate rule keeps `docs/adr/` + `PROJECT.md` the single source for
  decisions; agreements cannot silently fork a decision.
- **Neutral / accepted:** the tier ships as a **scaffold** — `_TEMPLATE.md` + README + one committed
  seed — with no write tooling until Phase 14; humans add agreements by hand in the interim.
- **Accepted:** the `two-plane-memory` skill's reworded source is not yet emitted to `.opencode/` /
  `.claude/` until Phase 15; the runtime copy lags the source for one milestone beat.

## Errata

*2026-07-16 (Phase 14 / MEM2-04). Appended, not edited: no decision word above is altered. Permitted
by [`README.md`](README.md) — "Fixing typos/links is fine; changing the recorded decision is not."
This corrects a factual claim in `### Consequences`, not the decision in `## Decision Outcome`, so
supersede-with-a-new-ADR is not the right instrument.*

**The "one committed seed" does not exist, and never did.** The `### Consequences` bullet above
states the tier ships as "a **scaffold** — `_TEMPLATE.md` + README + one committed seed". Only the
first two shipped. Verifiable:

```
$ git ls-files .memory/agreements/
.memory/agreements/README.md
.memory/agreements/_TEMPLATE.md
```

Commit `96b8db2` ("docs(memory): add working agreements tier") added exactly those two files. No
seed was ever removed — none was ever written.

**The empty active set is CORRECT — do not "repair" it.** This is the load-bearing half of this
errata. An agent reading the claim above, finding the directory empty, and helpfully authoring a
seed agreement would have to **invent user feedback** to fill the `provenance:` stamp. That is
precisely the anti-invent violation this channel is designed to prevent (§2 property 2: "an agent
**must not invent** entries"; threat T-13-01). An agreement exists only because a user gave explicit
process feedback. Zero feedback so far means zero agreements — that is the channel working, not a
defect.

The error is instructive rather than embarrassing: a ratified record on the constitution plane
asserted a fact that no test or gate checked, and it survived until someone diffed the claim against
`git ls-files`. That is the same failure mode Phase 13 caught three times (a prose guarantee with no
test behind it). The correction is a dated note citing falsifiable evidence — not manufactured
evidence retrofitted to match the claim.

**Scope:** the model, the four-plane decision, the tier's shape, and the reframe in
`## Decision Outcome` are all unaffected and remain in force.
