## What this instance is

The domain seed the harness template was extracted from: a reverse-engineered **semiconductor
equipment event-log parser** pipeline. It exercises the full harness — contract-first schemas, the
§4.3–4.6 polyglot normalization boundary, golden equivalence, and the drift/commit gates — against a
real domain, so the template's guarantees are proven end-to-end rather than in the abstract.

## Instance-local rules

- **Parser/converter = .NET 10, CPU-bound.** Lives in `components/` + `libs/dotnet/`. The Python
  golden-runner (core) spawns it via `subprocess.run([...], shell=False)` — **process/file/DB
  boundary only**, never in-process interop.
- **This instance's language set is declared in `harness/project.toml`** (`[[languages]]` .NET 10 +
  Python/uv). The template's active-instance slot points here.
- **.NET execution is egress-deferred (BOOT-01).** The env has no .NET 10 SDK; `dotnet test` and the
  live toy-converter spawn are gated-skipped, and the golden comparison path is proven green via the
  recorded-output twin under `tests/recorded/`. Do not treat the SKIP as a failure.
- **Uses the core, does not fork it.** Normalization is the harness's language-neutral
  `libs/python/normalize` core, cross-validated against this instance's `libs/dotnet` twin through
  the shared `libs/normalize-fixtures` corpus. Never add a second normalizer here.

## Non-negotiables (restated per-instance — P11 backstop)

1. **Contract-first.** `examples/log-parser/contracts/` is the source of truth for this instance;
   code that disagrees with the schema is wrong. Contract changes carry the golden / contract-drift
   gate against this instance's `contracts/.hashes/manifest.json`.
2. **§4.3–4.6 polyglot boundary invariants.** Cross-language equivalence is checked only **after**
   the shared canonicalization core: UTF-8 with **BOM** stripped, forced **LF**, InvariantCulture
   `.` decimals, tolerance-aware float compare, deterministic key/row ordering, **UTC** ISO-8601
   timestamps, explicit TSV escape + null-vs-empty token. Language boundary = process/file/DB only.
3. **Constitution plane is gated (machines gate, humans ratify).** Do **not** self-write this
   instance's `contracts/`, `golden/`, or the root `docs/adr/`. Golden baselines are human-promoted
   via `/golden-approve`; ADRs are append-only.
4. **Derived plane is not hand-edited.** Regenerated by `tools/memory_regen`.
